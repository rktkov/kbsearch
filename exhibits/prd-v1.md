# PRD: Semantic Search over Documents

**Версия:** 1.0
**Автор:** AI-агент (черновик)
**Статус:** Ready for development

## 1. Обзор

Смысловой поиск по базе знаний: пользователь вводит запрос на естественном языке,
система возвращает релевантные фрагменты документов.

## 2. Цели

- Дать пользователям быстрый доступ к нужной информации.
- Снизить нагрузку на поддержку.
- Использовать современный подход на основе векторных эмбеддингов.

## 3. Пользователи

- Сотрудник, который ищет ответ в документации.
- Новый сотрудник на онбординге.
- Автор документации.

## 4. Функциональные требования

| ID | Требование |
|---|---|
| FR-1 | Загрузка документов в систему |
| FR-2 | Разбиение документов на фрагменты |
| FR-3 | Генерация эмбеддингов и сохранение в векторной базе |
| FR-4 | Поиск по запросу с выдачей top-K результатов |
| FR-5 | Поддержка форматов: PDF, DOCX, Markdown |
| FR-6 | Веб-интерфейс с полем поиска |

## 5. API

```
POST /ingest          — загрузить документы
GET  /search?q=...    — поиск
GET  /health          — проверка живости
```

## 6. Технологический стек

- Go 1.22
- SQLite + векторное расширение (sqlite-vec)
- Ollama, модель bge-m3
- net/http, html/template

## 7. Критерии приёмки

- Поиск работает.
- Результаты релевантны запросу.
- Интерфейс открывается в браузере.
